ถ่ายอย่างไรให้อ่านแม่น

ได้มาจากการทดลองกับภาพจำลองจากกล้องมือถือ 100 ภาพ

  1. ถือห่างประมาณหนึ่งคืบ ถ้าใกล้เกินไปกล้องจะโฟกัสไม่ทัน ถ้าไกลเกินไปตัวหนังสือจะเล็กจนอ่านผิด
  2. ให้ข้อความอยู่ในกรอบกลางจอ ระบบอ่านเฉพาะในกรอบ เลขหน้าและหัวกระดาษด้านนอกจะไม่ถูกอ่าน
  3. รอให้กรอบเป็นสีเขียว แปลว่าภาพนิ่งพอแล้ว ถ้ากด "อ่านเลย" ระบบจะรอให้ภาพนิ่งเองสูงสุด 3 วินาที
  4. ในที่มืด เปิดไฟฉาย ปุ่มไฟฉายจะขึ้นมาเองถ้ามือถือรองรับ
